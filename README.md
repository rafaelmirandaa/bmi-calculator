# BMI Calculator

A responsive BMI (Body Mass Index) calculator built with HTML, SCSS, and JavaScript. Users can calculate their BMI using either metric or imperial units and receive their BMI result and healthy weight range.

## 🚀 Features

- Calculate BMI instantly as the user enters their information.
- Support for metric and imperial units.
- Display of BMI category.
- Healthy weight range calculation.
- Responsive design for mobile, tablet, and desktop.
- Semantic HTML structure.
- Accessible form controls.

## 🛠️ Built With

- HTML5
- SCSS
- JavaScript
- Vite

## 📱 Responsive Design

The project was designed to provide a good user experience across:

- Mobile devices
- Tablets
- Desktop screens
